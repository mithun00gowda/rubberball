# rubberball

This application is a digital scoring solution designed specifically to digitize the unstructured nature of 'Gully Cricket.' It utilizes a local database to persistently store comprehensive match details, including individual player performances, run rates, and team summaries. The system replaces manual scorekeeping, allowing users to generate historical statistics and retrieve past match data instantly. By digitizing these records, the app creates a professional statistical profile for amateur street cricket players.
